## Pitstop 0.1.0

The first release: a clean NVIDIA driver manager that replaces the NVIDIA App.

- **Driver page:** your GPU, the installed driver and its branch, and the newest Game Ready and Studio drivers from NVIDIA with release notes.
- **Clean install:** official package from NVIDIA's servers only, signature-checked, unpacked down to the display driver (plus PhysX, HD Audio or USB-C if you want them). No NVIDIA App, no telemetry. Optional clean install and telemetry task removal.
- **Restore point** before every install (can be turned off).
- **Saved drivers:** the last 3 installed packages, reinstall any in one click.
- **Game settings:** search the driver's game profiles and change max frame rate, low latency mode, V-Sync, power management, texture filtering, shader cache size and G-SYNC. Export and import as a file.
- **History** of every install and rollback.
- **Tray alerts** for new drivers (optional), start with Windows.
- Admin rights only at the moment they're needed.
- Suite standards: 14 themes plus Hangar theme files, accent colors, built-in updater with Stable/Beta channels and automatic rollback, portable mode, `Ctrl+,` for Settings.
